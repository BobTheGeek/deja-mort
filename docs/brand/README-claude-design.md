# DÉJÀ MORT — logo assets

svg/   lockup-* = PRIMARY lockups (mark + wordmark, ± tagline; dark, light, mono-transparent).
       stacked-*/inline-* = wordmark-only lockups. mark-* = mark alone.
       Lockup SVGs use live text (Archivo Medium wordmark, Inter Regular tagline, via Google Fonts @import); accent strokes are drawn geometry positioned for Archivo Medium's metrics. -tagline variants include the line; plain variants do not. The tagline never appears with the mark alone.
       For outlined versions: open in Illustrator/Inkscape/Figma with Archivo installed, then Create Outlines / Object to Path.
png/   mark-N, mark-mono-N (transparent) and app-icon-N (dark tile) at 1024, 512, 256, 128, 64, 48, 32, 16.
png/lockups/  rasters captured from the asset sheet (authoritative for accent placement): lockup-* primary, stacked-*/inline-* wordmark-only.

Type: Archivo (Omnibus-Type) and Inter (Rasmus Andersson), both SIL Open Font License 1.1 — https://fonts.google.com/specimen/Archivo · https://fonts.google.com/specimen/Inter
Tagline: Inter Regular at 38% of wordmark cap height, #F0F0F0 on dark / ink on light; gap above ≈ 1.35× the wordmark line gap.
Colors: ink #D7DAE0 / #151619 on light; ground #0B0C0F / #ECEDEF; accent #D9A05B / #C2853E on light.
